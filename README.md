📦 FoundItBro – Lost & Found Web App

A simple and responsive Lost & Found web application that helps users report lost items, submit found items, and browse available listings. Built using HTML, CSS, and JavaScript, this project focuses on usability and clean UI.

🚀 Features
🔍 Report lost items easily
📥 Submit found items
📋 View all reported items in one place
📱 Fully responsive design
🍔 Mobile-friendly navigation (hamburger menu)
🎯 Simple and intuitive user interface
🛠️ Tech Stack
HTML5 – Structure of the application
CSS3 – Styling and responsiveness
JavaScript (Vanilla JS) – Functionality and interactions
🧠 How It Works
Users can navigate between sections like Home, Report, and View Items
Lost or found items are submitted via forms
JavaScript handles page switching and dynamic updates
UI is optimized for both desktop and mobile screens
